# SHC Work Hub（スマホ版）

SHC Work Hub の勤務を、スマホから入れるための画面です。

- この中には、画面の作り（HTML と画像）だけが入っています。勤務の記録・名前・客先などのデータは入っていません。
- データは、使う人それぞれの Dropbox の「Apps/SHC Work Hub」フォルダに置きます。この画面は、ログインした人の Dropbox だけを読み書きします。
- PC の SHC Work Hub が、そのフォルダを2分ごとに見て、勤務の記録に取り込みます。

開く：https://masaonishi.github.io/shc-work-hub/
